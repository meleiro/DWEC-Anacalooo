Modularidad y manejo asíncrono en JavaScript

1. Explicación del tema

La modularidad y el manejo asíncrono son pilares del desarrollo moderno en JavaScript y React. La modularidad permite dividir el código en módulos reutilizables y el manejo asíncrono evita bloquear la ejecución al trabajar con procesos que tardan (como peticiones a APIs).

2. Esquema mental

MODULARIDAD Y ASINCRONÍA
│
├── MÓDULOS ES6
│   ├─ export / import
│   └─ Organización del código
│
├── CALLBACKS
│   ├─ Funciones que se ejecutan después
│   └─ Problema: "callback hell"
│
├── PROMESAS
│   ├─ then(), catch(), finally()
│   └─ Estados: pending, fulfilled, rejected
│
└── ASYNC / AWAIT
    ├─ await → espera la resolución
    ├─ try / catch → manejo de errores
    └─ Código más limpio
